# Botpoly

Bot headless controlado por Telegram, con riesgo y contabilidad persistentes. Consulta [INIT.md](INIT.md) para instalación, comandos, copias y operación.

Node 24.20.0 · pnpm 10.32.1 · `pnpm install --frozen-lockfile --ignore-scripts` · `pnpm build` · `pnpm start`.

Paper es simulado. Live exige activación externa y evidencia revisada; Telegram no puede activarlo. Una parada persiste y solo se reanuda con `/resume` confirmado y límites satisfechos.
